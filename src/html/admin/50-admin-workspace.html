🔐 Firebase Account Setup

Legacy username accounts are disabled. They only stored password hashes in the database and were not secure identities.
  1. Create the email/password user in Firebase Authentication.
  2. Copy its UID.
  3. Add that UID under /admins as true for owner/admin or staff for staff.
  4. Use Staff Access to assign the staff member's module permissions.
